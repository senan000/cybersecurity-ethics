# Cybersecurity Ethics

## Description

This repository focuses on cybersecurity ethics, responsible vulnerability disclosure, and professional responsibility in cybersecurity.

The project explores how cybersecurity professionals should respond when discovering vulnerabilities, especially when the vulnerability affects sensitive data or third-party software.

The main goal is to understand how to balance **public safety, responsible disclosure, professional responsibility, transparency, and accountability**.

## Key Concepts

### Responsible Disclosure

Responsible disclosure is the practice of privately reporting a security vulnerability to the affected vendor or organization and allowing reasonable time for investigation and remediation before public disclosure.

### Minimize Harm

Cybersecurity professionals should prioritize protecting users, systems, and sensitive information while avoiding unnecessary damage.

### Transparency

Security incidents and vulnerabilities should be communicated accurately to relevant stakeholders without unnecessarily exposing sensitive technical information.

### Accountability

Security decisions and communications should be documented so that actions can be reviewed and justified later.

### Professional Responsibility

Cybersecurity professionals should follow applicable laws, organizational policies, professional codes of ethics, and recognized security practices.

* GDPR
* HIPAA

* Least privilege
* Firewall restrictions
* Security monitoring
* Vulnerability patching
* Temporary disabling of vulnerable functionality
* Incident response procedures
* Vendor coordination
